# 浏览器材料导出助手

这是 Canvas Synapse 的可选、无需构建的 Chrome / Edge 扩展。它从用户当前已登录的交大课堂播放页导出一节课的 **JSON 材料包**，用于本地应用的“导入 JSON”功能。

## 使用

1. 在 Chrome 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择本目录 `extensions/lesson-export/`。
3. 打开自己有权查看的交大“课堂实录”播放页，等待节次、语音和 PPT 加载完成。
4. 点击扩展图标，点击“读取当前页面的节次”，选择一节回放。
5. 点击“导出 JSON 材料包”，保持弹窗打开，等待下载完成。
6. 在本地 Canvas Synapse 导入该 JSON 文件。导入后可查看时间对齐的 slides 与讲稿，并调用自己配置的模型整理知识点和问答。

## 导出的内容与边界

- 保存课程、节次、平台字幕原文、slides 图片地址、OCR 和时间索引。
- 字幕时间由平台毫秒转换为秒；PPT 时间本身为秒。
- **不下载视频或音频，不导出 Cookie、Canvas Token、JWT 或带登录参数的页面链接。**
- 本扩展不读取 Cookie、localStorage，也不向 Canvas Synapse 或其他服务器上传材料；下载文件由你手动导入应用。
- 图片仍为学校平台提供的远程地址。地址可能失效，应用也需要可访问学校网络；遇到失效可重新导入。
- 浏览器导出与 Canvas Token 导入使用不同课程命名空间（教学班编号与 Canvas 课程编号不是同一编号），不会自动合并；同一路径重复导入可更新材料。
- 浏览器适配器使用播放器已初始化的只读材料服务，目前识别 2026 年版 Vue/webpack 页面结构。学校更新播放器后可能需要适配。版本不匹配会显示错误并建议改用应用的 Canvas Token 导入，不会搜索或提取登录凭据作为后备。
- 无平台字幕或截图时会明确标注材料缺失，不生成虚构讲稿。

权限仅为 `activeTab` 与 `scripting`，且代码校验当前网址必须为 `v.sjtu.edu.cn` 的课程播放页。仅在你点击按钮时执行。源代码为本项目独立实现；私有接口的字段和调用方式用于协议互通，并非学校官方支持接口。

## 验证情况

后端协议解析、毫秒/秒换算、权限边界和无字幕场景由自动测试覆盖。本扩展需要在用户已登录的真实课程页完成一次人工验证；学校当前版本与平台权限可能导致不同结果。
