# Canvas Synapse

本地轻量课程工作台：把交大课堂回放中的 **每页 slides、对应讲稿、知识点和 AI 问答** 放在一起。

默认直接读取平台已有的语音转写和课堂画面。**程序没有视频下载流程**，不下载视频、不安装转写模型，也不需要 GPU、Node.js、Docker 或数据库服务。运行依赖仅为 **Python 3.9+ 自带标准库**。

## 开始使用

```bash
git clone https://github.com/FanqinZeng/Canvas-Synapse.git
cd Canvas-Synapse
python3 run.py
```

浏览器打开 **http://127.0.0.1:8765**。Windows 可运行 `py -3 run.py` 或双击 `start.bat`；macOS 可在终端运行 `sh start.command`。

端口被占用时：`python3 run.py --port 8877`。自定义资料位置：`python3 run.py --data-dir ./data`。默认资料保存在用户目录下的 `.canvas-synapse/`，退出后仍然保留。

首次打开可以点击 **体验示例课程**。示例是本项目编写的合成 VLSI 课件与讲稿，界面会明确标注，不是真实课堂。

## 获取自己的课程

1. 登录 [交大 Canvas](https://oc.sjtu.edu.cn)，进入「账户 → 设置 → 已批准的集成」，创建个人 Access Token。
2. 在本应用「设置」中保存 Canvas Token。
3. 点击「导入课程」，获取课程列表、选择课程与节次，再导入。
4. 程序只获取该节的文字转写、课堂图片地址、OCR 和时间索引。图片在查看时才读取，并受缓存上限约束。

凭证只输入到本机设置页，不要提交到 GitHub 或粘贴在聊天中。系统只能访问该 Token 本身有权访问的课程。

交大录播属于非公开接口，可能随着学校更新而变化。首次接入请对照原网页核对一节课的页数、时间和转写；缺少平台字幕时程序会明确显示缺失，不会生成替代讲稿或自动下载视频。

### 其他导入方式

- **JSON 资料包**：支持统一的课程、slides 和带时间的转写格式，见 [资料格式](docs/import-format.md)。界面可以下载示例 JSON；导出 JSON 后也可以重新导入。
- **从已登录的播放页导出**：仓库附带 [浏览器导出扩展](extensions/lesson-export/README.md)，用于当前课程页的 JSON 导出。它不会导出登录凭证，也不抓取视频。学校播放器发生变化时可能需要更新适配。

目前的 slides 来自平台课堂画面（可能包含网页、板书或代码），不保证是老师上传的原始 PPTX。任意原始 PDF/PPTX 文档上传与自动解析未包含在本版。

## 查看与整理

- 左侧切换课程和节次，中间浏览大图与缩略图；键盘左右箭头翻页。
- 每页查看「知识点」「老师讲稿」「我的笔记」。讲稿按时间重叠关联，跨页句子可能同时显示在两页；完整原始讲稿独立保留，导出时不重复。
- 收藏重点页、标记已复习、保存自己的笔记，通过全局搜索定位原文。
- 重复导入同一节课会保留个人笔记、收藏与复习状态；原材料变化后可重新 AI 整理。
- 导出 Markdown 包含课件文字、知识点、个人笔记与完整讲稿；JSON 用于备份和迁移。

### 配置模型

在「设置」填写提供商、协议、Base URL、模型名称和 API Key。模型名称使用你账号实际可调用的 ID。

| 提供商 | 协议 | Base URL 示例 |
| --- | --- | --- |
| 智谱 GLM 通用 API | Chat Completions | `https://open.bigmodel.cn/api/paas/v4` |
| OpenAI | Responses | `https://api.openai.com/v1` |
| OpenAI 兼容服务 | Chat Completions | 服务商提供的 API 地址 |
| 本机 Ollama 等兼容服务 | Chat Completions | `http://127.0.0.1:11434/v1` |

应用支持保存后测试连接，测试会发起一次真实模型请求。使用编程套餐或代理时，需自行确认其是否允许应用的普通 API 调用。

点击「AI 整理」会逐页、逐段处理材料，保存每页知识点与摘要。长材料按段处理，**不会直接截掉课堂后半部分**。模型失败会报告错误，已完成页仍然保留，可重试；原始讲稿不会被模型改写。

可选「发送 slide 图片」需要模型支持视觉输入。默认关闭，仅发送 OCR 和讲稿；开启后执行 AI 整理会将相应课堂图片发给所配置的模型服务。图片分析上限为每张 3MB。

### 侧栏问答

支持本页、本节、整门课程三个范围，多轮记录保存在本地。回答前检索原始 OCR、时间段讲稿及个人笔记，附带可点击的资料来源。引用可以跳转到对应课堂和 slide。

检索采用英文标识符与中文单字/双字的词法相关性排序，无需向量模型或额外数据库。它适合轻量个人课程库，但不等同于完整语义检索；概括整门课程时可能只检索到部分资料，回答会收到范围提示。模型仍可能出错，重要公式和课堂要求请核对来源。

## 本地数据与存储

- SQLite：课程、原始讲稿、知识点、笔记、进度和对话。
- 私有 `settings.json`：API Key、Canvas Token 和模型设置。Unix 权限为 `0600`，**没有加密**；请保护本机账号和备份。设置接口只返回「已配置」状态，不回传凭证。
- 图片缓存：按需缓存，最多约 **128MB**，超出后按最近使用时间淘汰，可在设置中清理。清理不会删除笔记或讲稿。
- 无视频、音频缓存；不包含云端同步或后台遥测。
- 数据目录和媒体文件已在 `.gitignore` 排除。JSON/Markdown 导出包含课程内容与个人笔记，分享前请自行检查。

服务只绑定 `127.0.0.1`，校验 Host、Origin 和修改请求类型，不提供远程多人部署。配置云模型时，选定的课程文本、对话上下文，以及你开启图片分析后的图片，会发送到你配置的模型服务。仅处理你有权访问和使用的课程资料。

## 验证与开发

```bash
python3 -m unittest discover -s tests -v
python3 -m compileall -q synapse run.py
```

测试覆盖时间单位转换、完整转写保留、跨页对齐、重复导入、中文检索、跨课程隔离、导入导出、模型流中断、配置脱敏、HTTP 接口和跨站请求拦截。测试不使用真实 Token 或付费 API。GitHub Actions 运行 Python 3.9/3.12/3.13 测试和 JavaScript 语法检查。

```text
synapse/
  server.py      本机 HTTP API、任务、缓存与 AI 整理
  canvas.py      Canvas → LTI → 平台转写与 slides
  materials.py   资料校验、时间对齐、轻量检索
  store.py       SQLite 与 Markdown/JSON 导出
  llm.py         GLM/OpenAI 兼容和 Responses 流式适配
  settings.py    本地私有配置
  static/        无构建前端
extensions/      课堂页资料包导出扩展
tests/           离线单元和 HTTP 集成测试
```
