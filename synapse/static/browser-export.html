从已登录的课堂页面导出

优先在工作台设置 Canvas Token 后导入。若希望沿用浏览器里的登录状态，可以使用仓库附带的可选导出扩展。

  1. 下载或克隆 Canvas Synapse 仓库。
  2. 在 Chrome / Edge 的扩展管理页面开启开发者模式，选择「加载已解压的扩展」，选中 extensions/lesson-export 文件夹。
  3. 打开已登录的交大课堂播放页面，点击扩展，选择一节课堂导出 JSON。
  4. 回到工作台的「导入课堂 → JSON 资料包」，选择刚导出的文件。

扩展不导出 Token、Cookie 或视频。它适配已知的课堂播放器版本；页面升级导致失败时请改用 Canvas Token 导入。真实学校登录态仍需首次使用时核对。
